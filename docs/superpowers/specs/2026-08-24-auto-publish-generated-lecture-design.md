# 新生成专属讲义自动加入领域知识库

## 目标

功能上线后，新生成且通过内容质量校验的专属讲义自动发布到其所属领域知识库，不再等待管理员逐条批准。历史资源不自动补入，由管理员后续批量确认。

## 适用范围

- 仅适用于 `resource_type=lecture` 的新生成资源。
- 以资源生成完成事件为触发点；不扫描或改写上线前的历史资源。
- “自动入库”仍使用现有知识库文档处理和索引服务，不能绕过文档索引校验。

## 自动入库条件

以下条件必须同时满足：

1. 资源为最新版本，且状态为 `ready`。
2. `validation_passed=true`。
3. `hallucination_detected=false`。
4. `review_status=approved`。
5. 资源标题、领域、正文均非空，标题不得为 `None`、`null` 或同类占位值。
6. 资源格式属于现有知识库支持的 `md`、`text` 或 `html`。
7. 当前资源版本和内容哈希没有已发布的知识库文档。

任一条件不满足时不得自动发布，并记录可诊断的失败原因。

## 状态流转

```text
生成中 -> 质量校验 -> ready/approved -> 自动入库 -> published
                         |
                         +-> 条件不满足 -> failed 或 publish_failed
```

自动发布成功后：

- 资源保持 `ready` 和 `approved`；
- 入库记录直接为 `published`；
- 写入 `published_at` 和自动入库审计信息；
- 通过领域字段确定目标领域知识库。

自动发布失败时，入库记录为 `publish_failed`，保留错误信息并允许管理员重试。质量校验失败的资源保持 `failed/pending`，不得创建可发布记录。

## 权限与职责

- 系统服务账号负责符合条件资源的自动发布，不要求学习者或教师点击申请，也不需要管理员批准。
- 管理员可以查看自动入库记录、查看校验结果、重试发布失败、下架或撤回已入库内容。
- 管理员继续负责历史资源的批量补入和异常处置。

## 幂等与版本规则

- 同一资源版本只能生成一份有效知识库文档。
- 重复生成完成事件不得重复创建文档或重复索引。
- 资源新版本使用新的内容哈希和文件名重新入库；旧版本保留历史记录。
- 已为 `published` 的记录不可再次发布；仅 `publish_failed` 允许重试。

## 展示规则

前端区分以下状态，避免把质量失败误称为人工待审核：

- 质量校验中
- 质量校验未通过
- 自动入库中
- 已加入领域知识库
- 入库失败，可重试

“待管理员审核”只用于仍保留人工审批的历史资源批量处理流程。

## 验收标准

1. 新生成、校验通过的专属讲义自动出现在正确领域知识库。
2. 合格资源不出现管理员批准按钮或 `pending` 入库申请。
3. 校验失败、标题缺失、领域缺失、正文为空的资源不会入库。
4. 重复事件不会产生重复文档。
5. 索引服务失败时展示原因并支持管理员重试。
6. 上线前历史资源不会被自动批量改写或入库。
