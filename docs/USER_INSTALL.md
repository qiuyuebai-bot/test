# 知域引擎：用户安装说明

## 安装

1. 获取 `知域引擎-Setup-<版本号>.exe`。
2. 双击安装程序，阅读并确认使用说明。
3. 选择安装位置；默认会在当前 Windows 用户下安装。
4. “在桌面创建知域引擎快捷方式”默认选中，可自行取消。
5. 安装完成后从桌面或开始菜单打开“知域引擎”。

软件启动时会自动准备本机服务，无需打开浏览器，也无需自行安装运行环境。

## 首次启动

第一次启动请创建管理员账号和密码。请保存好这组密码，软件不会提供固定的通用管理员密码。

进入系统后，若尚未设置 AI 服务，会显示配置引导。可以输入自己的 API Key、服务地址和模型名，或选择稍后配置。没有 Key 时，基础演示与规则能力仍可使用。

## 卸载

在 Windows **设置 → 应用 → 已安装的应用** 中找到“知域引擎”，选择卸载。卸载时可选择是否删除本机学习数据和 AI 服务配置：

- 选择“否”：保留数据，以后重新安装可继续使用。
- 选择“是”：删除当前 Windows 用户目录下的知域引擎数据，无法恢复。
