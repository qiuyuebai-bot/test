# 计算机组成与体系结构基础

## 指令执行过程
处理器通常经历取指、译码、执行、访存和写回等阶段，具体划分取决于微体系结构。程序计数器、寄存器组、算术逻辑单元和控制器共同完成指令执行。

## 存储层次
寄存器、缓存、主存和外存形成容量递增、速度递减的存储层次。局部性原理说明程序常重复访问近期或相邻数据，缓存通过利用这种规律减少平均访问时间。

## 总线与输入输出
总线或互连结构承载数据、地址和控制信息，输入输出设备通过控制器与处理器和内存交互。中断和直接内存访问可以减少处理器对设备传输细节的直接参与。

## 性能分析
系统性能需要结合指令数、每条指令周期数和时钟频率分析，不能只看单一频率指标。缓存命中率、分支预测、流水线停顿和并行度都会影响实际执行时间。

## 指令集与寻址方式
指令集规定处理器能够执行的操作、操作数类型和寄存器模型，寻址方式决定如何取得操作数。理解立即数、寄存器、直接和间接寻址，有助于分析编译结果、内存访问和程序执行效率。
