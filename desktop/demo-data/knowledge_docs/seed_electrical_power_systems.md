# 电力系统与继电保护基础

## 电力系统组成
电力系统包括发电、输电、变电、配电和用电环节。理解各环节的电压等级、运行目标和约束，是分析潮流与供电可靠性的基础。

## 三相交流基础
对称三相系统具有幅值相等、相位互差和相序确定等特征。线电压与相电压、星形与三角形连接的关系应结合电路约束进行判断。

## 潮流与短路分析
潮流分析用于计算节点电压、功率和线路传输，短路分析用于估计故障电流和设备承受能力。计算模型应明确网络参数、运行方式和故障类型。

## 继电保护原则
继电保护应满足选择性、速动性、灵敏性和可靠性。保护范围、整定配合和后备保护需要结合系统结构与故障风险设计。

## 供电安全与运维
供配电运维要执行停电、验电、接地和挂牌等安全措施，并定期检查绝缘、接地、温升和保护动作。操作记录和异常闭环同样重要。
