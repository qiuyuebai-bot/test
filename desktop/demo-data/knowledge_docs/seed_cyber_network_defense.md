# 网络防御与安全运营

## 网络资产盘点
防御的基础是知道有哪些主机、服务、账号和连接。资产盘点应包含负责人、重要性、暴露面和软件版本，并及时处理长期未维护资产。

## 纵深防御
纵深防御通过边界控制、网络分区、主机加固、身份权限和数据保护共同降低风险。单个设备失效时，其他层仍应限制攻击扩散。

## 入侵检测
入侵检测可以结合签名、异常行为和威胁情报发现可疑活动。检测规则要控制误报，并记录事件上下文、时间线和关联资产。

## 安全运营流程
安全运营包括告警分级、研判、处置、复盘和规则优化。处理过程应有明确责任人、升级路径和服务时间，避免告警长期无人跟进。

## 网络设备加固
网络设备加固包括关闭无用服务、限制管理来源、使用加密协议、更新固件和备份配置。变更前后应验证连通性与访问控制，避免防护措施造成业务中断。
