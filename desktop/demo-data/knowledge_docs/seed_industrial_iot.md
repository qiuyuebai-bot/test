# 工业互联网数据基础

## 设备数据采集
工业设备数据采集应明确设备标识、测点含义、采样周期和时间同步规则。采集链路需要处理断连、重复和乱序等常见情况。

## 数据质量检查
工业数据进入分析流程前，应检查缺失、异常、重复和单位不一致问题，并保留质量检查结果，避免未经说明的数据清洗影响判断。

## 告警与追踪
设备告警应关联设备、时间、指标和处理状态。通过统一事件编号可以追踪告警从产生、确认到关闭的完整过程。

## 边缘与平台协同
对实时性要求高或网络不稳定的场景，可在边缘侧完成采集、过滤、缓存和快速告警，再把必要结果汇聚到平台。边缘与平台之间应明确数据责任、时间同步和断线补传规则。

## 工业协议与数据模型
工业数据接入应明确协议、设备标识、测点语义、单位和质量码，避免只传输没有上下文的数值。统一的数据模型有利于跨设备比较、权限控制和后续分析复用。
