# 监督学习与模型评估

## 监督学习任务
监督学习使用带标签样本学习输入到输出的映射，分类输出离散类别，回归输出连续数值。任务定义应明确标签含义、预测时点和业务使用方式。

## 数据集划分
训练集用于拟合参数，验证集用于选择模型和超参数，测试集用于最终无偏评估。相似样本或同一对象的数据不能不加判断地分散到不同集合。

## 分类与回归指标
分类可使用准确率、精确率、召回率、F1和ROC-AUC，回归可使用MAE、MSE和R平方。指标选择应反映错误成本，不能只看总体准确率。

## 特征工程
特征工程包括缺失值处理、编码、缩放、筛选和构造。所有处理步骤都应由训练数据拟合并应用到验证和测试数据，防止评估信息泄漏。

## 模型解释与校准
模型解释可以帮助发现错误模式和不合理特征，概率校准则使输出概率更接近实际发生频率。上线前应检查分群表现和高风险错误。
