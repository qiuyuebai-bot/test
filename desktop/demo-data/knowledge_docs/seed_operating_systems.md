# 操作系统原理基础

## 进程与线程
进程是资源分配和保护的基本单位，线程是进程内可调度的执行流。线程共享进程资源，切换和通信成本较低，但也需要同步机制避免竞态。

## 调度与并发
调度器在多个可运行任务之间分配处理器时间，常见目标包括响应性、公平性和吞吐量。并发程序必须明确共享状态、临界区和同步顺序。

## 虚拟内存
虚拟内存为进程提供独立地址空间，并通过页表把虚拟地址映射到物理内存。分页和按需调页可以提高内存利用率，但频繁缺页会导致性能下降。

## 文件与权限
文件系统负责组织持久化数据、维护元数据并提供访问接口。权限模型应区分文件所有者、用户组和其他主体，服务进程只应获得完成任务所需的最小权限。

## 同步与死锁
互斥锁、信号量和条件变量可用于协调并发线程，但加锁顺序不当可能造成死锁。设计同步方案时应明确资源占用关系，尽量缩小临界区，并为超时、取消和故障恢复保留处理路径。
