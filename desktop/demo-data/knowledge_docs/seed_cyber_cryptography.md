# 密码学与安全协议基础

## 密码学安全目标
机密性、完整性、身份认证和不可否认性是常见安全目标。一个算法是否安全取决于密钥管理、使用模式和协议上下文，不能只看算法名称。

## 对称与非对称密码
对称密码使用共享密钥，适合高效加密大量数据；非对称密码使用公钥和私钥，适合密钥交换和签名。实际系统常结合二者使用。

## 哈希与消息认证
密码哈希用于生成固定长度摘要，常用于完整性校验和口令保护。消息认证码还需要共享密钥，使用时要防止重放并明确编码范围。

## 数字签名与证书
数字签名可证明消息由对应私钥持有者生成且内容未被修改。证书把公钥与身份绑定，验证链、有效期和吊销状态都必须检查。

## 密钥生命周期
密钥管理包括生成、分发、存储、轮换、备份、吊销和销毁。密钥不应硬编码在源码或日志中，权限和审计要覆盖整个生命周期。
