# 科学素养与技术伦理

## 科学问题与证据
科学问题应能够被观察、测量或通过合理模型检验。结论需要对应证据范围，不能把个例、相关关系或权威表述直接当作普遍规律。

## 假设与可证伪性
好的假设给出明确预测，并允许通过实验或数据证明其不成立。研究过程中应同时考虑支持证据和反例，避免只寻找符合预期的信息。

## 数据与不确定性
测量结果包含误差和不确定性，数据分析应报告样本范围、误差来源和适用条件。精确的数字不代表结论一定可靠，还要检查数据质量和方法。

## 技术伦理
技术应用应评估安全、公平、隐私、可及性和环境影响。设计者需要明确责任边界，建立风险评估、人工监督和问题申诉机制。

## 科学传播
科学表达应区分事实、推断和观点，说明来源、时间和限制。面对复杂结论，要避免夸大确定性，并用目标受众能够理解的方式解释。
