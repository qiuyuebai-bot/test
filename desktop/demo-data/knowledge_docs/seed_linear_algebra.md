# 线性代数基础与计算应用

## 向量空间与线性组合
向量可以表示有方向的量，也可以作为数据和状态的坐标表示。线性组合、张成、线性相关与基用于描述向量空间的结构和维数。

## 矩阵与线性方程组
矩阵可表示线性变换或方程组的系数。高斯消元通过初等行变换求解方程组，同时能够帮助判断解的存在性和自由度。

## 特征值与分解
若非零向量经过线性变换后方向不变，只发生比例缩放，该比例称为特征值。特征值分解和奇异值分解常用于降维、信号处理和稳定性分析。

## 内积与最小二乘
内积提供长度、夹角和正交关系，正交投影可把问题转化为在子空间中寻找最接近的表示。最小二乘法通过最小化残差平方和估计线性模型参数。

## 线性变换与坐标表示
线性变换保持向量加法和数乘关系，矩阵是选定基底后对线性变换的坐标表示。改变基底可以简化计算或突出问题结构，坐标变换时必须保持维度和映射方向一致。
