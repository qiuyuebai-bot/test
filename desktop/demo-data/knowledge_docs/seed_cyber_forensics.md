# 安全事件响应与数字取证

## 事件响应阶段
事件响应通常包括准备、识别、遏制、根除、恢复和复盘。阶段之间可以迭代，但每一步都应记录判断依据、操作人员和时间。

## 证据保全
取证前应明确授权和范围，尽量保留原始介质并计算校验值。证据交接要记录人员、时间、操作和存放位置，保证证据链完整。

## 日志时间线
时间线分析需要统一时区和时钟偏差，关联登录、进程、网络、文件和配置事件。时间线应区分事实记录与分析推断，并保留原始日志来源。

## 恶意活动分析
分析可从初始访问、持久化、提权、横向移动和数据影响等阶段梳理行为。应使用隔离环境处理可疑文件，避免在生产环境中直接执行。

## 事件报告
报告应说明影响范围、发现过程、证据、处置措施、残余风险和改进建议。敏感信息按授权范围共享，结论应区分已确认事实与待验证假设。
