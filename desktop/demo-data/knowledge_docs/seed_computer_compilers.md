# 编译原理与程序语言基础

## 编译过程
编译器通常经历词法分析、语法分析、语义分析、中间表示、优化和目标代码生成。每个阶段都应输出明确的数据结构和错误信息。

## 词法分析
词法分析把字符流转换为记号流，识别关键字、标识符、字面量和运算符。有限自动机可以描述规则，最长匹配和优先级需要明确。

## 语法分析
语法分析根据文法判断记号序列是否符合结构，并构造语法树或抽象语法树。递归下降、LL和LR方法在适用文法与实现复杂度上各有差异。

## 语义与类型检查
语义分析检查作用域、声明使用、类型兼容和控制流约束。符号表记录名字与属性，类型系统可以在运行前发现一部分错误。

## 中间表示与优化
中间表示为优化和多目标代码生成提供统一基础。常见优化包括常量传播、死代码删除和公共子表达式消除，必须保持程序语义不变。
