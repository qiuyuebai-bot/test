# 大学物理力学基础

## 运动学描述
位置、位移、速度和加速度描述物体运动状态的变化。建立坐标系、明确参考系并区分矢量与标量，是解决运动学问题的第一步。

## 牛顿运动定律
牛顿第二定律把合外力与加速度联系起来，受力分析应画出清晰的隔离体图并列出约束条件。惯性系的选择会影响方程形式。

## 动量与角动量
动量定理适合分析碰撞和短时相互作用，角动量定理适合分析转动系统。守恒条件必须针对系统边界和外力矩进行判断。

## 功与机械能
功描述力在位移方向上的能量传递，动能定理和机械能守恒可以简化运动分析。非保守力存在时，应明确能量损失或转换路径。

## 刚体转动
刚体转动涉及角速度、角加速度、转动惯量和力矩。平行轴定理与转动动能可以把几何分布和动力学联系起来。
