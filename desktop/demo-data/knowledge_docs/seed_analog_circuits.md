# 模拟电路基础

## 基本电路定律
欧姆定律描述电阻、电压和电流之间的关系，基尔霍夫电流定律和电压定律分别对应节点电荷守恒与回路能量守恒。分析前应明确参考方向、节点和回路。

## 二极管与晶体管
二极管具有明显的单向导电特性，可用于整流、限幅和保护。晶体管可在合适偏置下工作于放大或开关状态，实际电路需要关注工作点、功耗和温度影响。

## 运算放大器
理想运算放大器常在负反馈条件下近似满足输入端电压相等、输入电流为零的分析条件。反相、同相、加法和积分电路的增益由反馈网络决定，使用时要检查带宽和输出摆幅。

## RC电路与滤波
电阻和电容构成的一阶网络具有由时间常数决定的动态响应，可用于低通、高通和积分近似。设计滤波器时应同时考虑截止频率、幅频特性、相位响应和负载影响。

## 偏置与小信号分析
晶体管放大电路需要先确定静态工作点，再在工作点附近建立小信号模型分析增益、输入输出电阻和频率响应。偏置不稳定或信号过大都可能使器件离开放大区并产生失真。
