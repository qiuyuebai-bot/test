# 软件测试与质量保障

## 测试层次
单元测试关注函数或组件，集成测试关注模块协作，系统测试验证完整流程，验收测试则确认业务目标。不同层次应承担不同的缺陷发现责任。

## 测试用例设计
用例应覆盖正常流程、边界值、异常输入、权限差异和状态转换。等价类、边界值分析和场景法可以帮助减少遗漏，但不能替代业务判断。

## 自动化测试
自动化测试适合重复执行、结果明确且环境稳定的检查。测试数据、依赖服务和时间因素应可控，否则自动化用例会产生大量不稳定失败。

## 缺陷管理
缺陷记录应包含复现步骤、实际结果、预期结果、环境和证据。修复后要进行回归验证，并根据严重程度、影响范围和发生频率安排优先级。

## 质量指标
测试质量可结合通过率、缺陷密度、逃逸缺陷、覆盖率和修复周期评价。指标应辅助发现风险，不能把单一覆盖率当作软件质量的充分证明。
