# 数字电路基础

## 数制与逻辑门
数字系统用有限个离散电平表示信息，二进制是最常见的数制。与、或、非及其组合门电路可以实现布尔函数，真值表是验证逻辑关系的直接工具。

## 组合逻辑
组合逻辑电路的输出只由当前输入决定，译码器、编码器、多路选择器和加法器是典型模块。设计时要化简逻辑表达式，并检查竞争、冒险和传播延迟。

## 时序逻辑
时序逻辑电路的输出与输入及历史状态有关，触发器、寄存器和计数器是常见组成。同步设计通常使用统一时钟，并满足建立时间、保持时间和复位要求。

## 数字系统实现
复杂数字系统可按数据通路和控制器划分，使用状态机描述控制过程。采用 HDL 或可编程逻辑器件实现时，需要通过仿真、约束检查和板级测试验证功能与时序。

## 模数转换与时钟设计
模数转换涉及采样、量化和编码，采样频率应满足信号带宽要求，并注意混叠和量化误差。数字系统还需合理分配时钟、复位和跨时钟域信号，避免亚稳态影响逻辑可靠性。
