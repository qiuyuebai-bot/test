# 智能制造设备预测性维护

## 维护策略比较
事后维修在故障后处理，预防性维护按时间或使用量保养，预测性维护则根据状态和风险安排维护。策略选择要综合停机损失、备件成本和监测成本。

## 设备状态指标
振动、温度、电流、压力、噪声和润滑状态都可反映设备健康。指标应与具体故障机理关联，并记录工况，避免把负载变化误判为故障。

## 故障特征与诊断
诊断流程通常包括信号清洗、特征提取、状态分类和根因分析。频域特征、趋势特征和变化点可以互相补充，但应通过已知故障样本验证。

## 剩余寿命预测
剩余寿命预测估计设备距离性能阈值或故障的时间。模型应报告预测区间和不确定性，并结合检修窗口制定可执行的维护建议。

## 维护闭环管理
预测结果只有转化为工单、备件和现场反馈才有价值。应记录告警是否准确、维护后状态和实际故障原因，用闭环数据更新阈值与模型。
