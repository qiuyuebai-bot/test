# 智能制造机器视觉检测

## 视觉检测系统组成
典型系统由光源、镜头、相机、采集卡、处理软件和执行机构组成。选型应围绕缺陷尺寸、节拍、视场、景深和环境光稳定性展开。

## 成像质量控制
稳定成像比复杂算法更重要。应控制曝光、焦距、光照方向和工件定位，减少反光、阴影、运动模糊和背景变化带来的误检。

## 图像预处理
灰度化、去噪、增强、阈值分割和形态学操作可以突出目标区域。处理链应保留中间结果，便于定位参数不合适造成的漏检和误检。

## 缺陷识别与评估
规则方法适合边界清晰、样本稳定的缺陷，机器学习方法适合复杂外观模式。评价时应分别统计准确率、漏检率、误检率和推理延迟。

## 现场部署与维护
现场部署需考虑振动、温度、粉尘、设备节拍和网络中断。应建立样本回收、模型版本、参数变更和人工复核机制，持续维护检测效果。
