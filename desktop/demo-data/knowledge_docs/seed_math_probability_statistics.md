# 概率论与数理统计基础

## 随机事件与概率
随机事件描述不确定结果的集合，概率用于刻画事件发生的可能性。加法公式、乘法公式和条件概率是处理复合事件的基本工具。

## 随机变量与分布
随机变量把随机结果映射为数值，分布函数、概率质量函数和密度函数描述其规律。离散与连续情形在求概率时使用不同表达方式。

## 期望与方差
期望描述平均水平，方差描述波动程度。线性性质、协方差和相关系数有助于分析多个随机变量之间的关系，但相关不等于因果。

## 大数定律与中心极限定理
大数定律说明样本平均在一定条件下趋近总体期望，中心极限定理解释大量独立因素叠加后的近似正态性。使用时应检查样本和独立性条件。

## 统计推断入门
参数估计和假设检验利用样本推断总体特征。结果应报告估计值、区间或显著性，同时说明抽样方式、模型假设和不确定性。
