# 大学物理热学与热力学

## 温度与平衡
温度刻画热平衡状态，热力学系统需要明确边界、状态变量和外界交换。平衡态、准静态过程和非平衡过程不能混为一谈。

## 理想气体模型
理想气体模型忽略分子体积和相互作用，状态方程把压强、体积和温度联系起来。模型适用于一定条件，不能无条件外推到高压或低温。

## 热力学第一定律
第一定律表达能量守恒，内能变化等于吸收热量与系统对外做功的组合。使用时必须统一功和热的正负号约定。

## 熵与过程方向
熵用于描述能量品质和不可逆性，孤立系统熵不会减少。实际过程中的摩擦、传热温差和混合都会产生熵。

## 热机与制冷机
热机把部分热量转化为功，制冷机通过外界做功实现热量逆向传递。效率和性能系数受热源温度、过程可逆性和工程损耗影响。
