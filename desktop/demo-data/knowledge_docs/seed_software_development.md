# 软件开发工程实践基础

## 需求与接口设计
软件开发应先明确需求边界、输入输出和异常情况，再设计稳定的接口契约。接口命名、参数类型和错误响应应保持一致，并通过文档和测试共同维护。

## 代码质量
代码评审应关注可读性、边界条件、错误处理和可测试性。复杂逻辑应拆分为职责清晰的函数，并使用自动化测试验证关键路径。

## 发布与复盘
服务发布前应完成构建、测试和配置检查。发布后需要监控错误率和响应时间，出现异常时保留日志并通过复盘改进开发流程。

## 版本控制与协作
版本控制应通过小步提交、清晰说明和分支协作保留变更轨迹。合并前需要经过代码评审和自动化检查，出现问题时可以依据提交记录定位并回滚。

## 依赖与配置管理
项目应锁定关键依赖版本，区分开发、测试和生产配置，不把密钥写入代码或提交到仓库。配置变更需要经过检查并保留可恢复的发布方案。
