# 统计推断与实验分析

## 描述统计
均值、中位数、分位数、方差和标准差描述数据的集中趋势与离散程度。分析前应同时查看分布、异常值和样本量，避免只依赖单个汇总指标。

## 概率与抽样
概率模型用于表达不确定性，抽样方法决定样本能否代表目标总体。随机抽样、分层抽样和便利抽样会带来不同的偏差与适用条件。

## 置信区间
置信区间给出统计量不确定性的范围，区间宽度受样本量、波动和置信水平影响。它不是参数落在区间内的概率陈述，应结合研究设计解释。

## 假设检验
假设检验通过原假设、备择假设、检验统计量和显著性水平判断证据强弱。统计显著不等于实际重要，结果还要结合效应量和业务成本。

## 实验设计
实验设计应明确处理、对照、随机化、重复和评价指标。控制混杂因素能够提高因果解释能力，实验结论要说明样本范围和外推限制。
