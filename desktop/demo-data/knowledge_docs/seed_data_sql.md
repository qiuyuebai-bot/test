# 数据分析与SQL实践

## 查询与筛选
SQL查询通过选择字段、过滤记录和排序结果完成基础分析。筛选条件要明确空值、时间边界和大小写规则，避免结果与业务口径不一致。

## 分组聚合
分组聚合可以计算计数、求和、平均值和分位数等指标。聚合前要确认粒度，防止多表连接导致记录重复和指标被放大。

## 表连接
内连接只保留匹配记录，左连接保留左表全部记录。连接前要检查键的唯一性、数据类型和缺失情况，并用抽样结果验证连接是否符合预期。

## 窗口函数
窗口函数可以在不减少行数的情况下计算排名、累计值、移动平均和分组内比较。使用时应明确分区字段、排序字段和窗口范围。

## 分析结果校验
SQL结果应通过总量核对、分组汇总、抽样明细和历史趋势进行校验。重要指标要固定口径、保留查询版本并记录数据更新时间。
