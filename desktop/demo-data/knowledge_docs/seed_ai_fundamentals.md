# 人工智能通识与工程应用

## 人工智能与机器学习
人工智能是利用计算系统完成感知、推理、学习和决策等任务的综合领域，机器学习是其中通过数据学习模式的一类方法。深度学习使用多层参数化模型提取表示，但并不等于所有人工智能。

## 训练与泛化
模型训练通过优化目标函数调整参数，泛化能力表示模型处理未见样本的表现。过拟合、数据分布变化和数据泄漏会使离线指标与实际效果产生差异。

## 生成式人工智能
生成式模型根据输入条件产生文本、图像或其他形式的内容。使用时应明确任务边界，提供可核验的上下文，对关键事实进行来源核查，并保留人工复核环节。

## 可信与负责任应用
人工智能系统需要关注安全、隐私、公平、可解释性和责任边界。上线前应进行数据治理、权限控制、异常监测和效果评估，上线后持续记录版本与问题反馈。

## 模型部署与持续评测
模型部署需要明确输入输出契约、资源限制、版本标识和回滚策略。上线后应持续监测数据分布、准确性、延迟和异常样本，定期用新数据评测，避免只依赖一次离线测试。
