# 职业素养与岗位发展

## 岗位能力画像
岗位能力画像应同时描述专业知识、实践技能、通用能力和行为要求。学习者可以对照目标岗位拆分差距，再按重要性和紧迫性安排提升计划。

## 沟通与协作
有效沟通需要先确认目标和上下文，再用清晰、可执行的方式表达信息。团队协作中应及时暴露风险、尊重不同意见并对共同结果负责。

## 问题解决
解决问题可以经历现象描述、原因假设、证据收集、方案比较、实施验证和复盘。避免直接跳到结论，并通过数据或实验确认改进是否有效。

## 职业规范
职业规范包括守时守信、保护信息、遵守安全要求、正确记录和尊重知识产权。涉及高风险系统时，应按授权范围操作并及时报告异常。

## 持续发展计划
职业发展计划应包含目标岗位、能力差距、学习资源、实践任务和阶段性证据。定期根据反馈和岗位变化调整计划，用可验证成果而非学习时长衡量进步。
