# 数据可视化与信息表达

## 图表选择
柱状图适合比较类别，折线图适合观察趋势，散点图适合分析关系，箱线图适合比较分布。图表类型应由问题和数据结构决定，而不是由样式偏好决定。

## 坐标与尺度
坐标轴、单位、刻度和零点会显著影响读者判断。截断坐标轴或使用不一致尺度可能夸大差异，应在确有必要时清楚标注。

## 颜色与编码
颜色、位置、长度和形状都可编码数据，但同一含义应保持一致。配色要考虑对比度、色盲可读性和打印效果，不应让装饰压过数据。

## 交互式分析
筛选、钻取、联动和提示可以帮助用户探索数据。交互应有清晰状态、默认视图和空结果提示，并注意大数据量下的响应时间。

## 叙事与结论
可视化叙事应围绕问题组织证据，区分观察到的事实、推测和建议。结论要给出时间范围、样本范围和限制，避免把相关性描述成因果关系。
