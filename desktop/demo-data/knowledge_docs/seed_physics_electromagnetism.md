# 大学物理电磁学基础

## 库仑定律与电场
库仑定律描述点电荷之间的作用力，电场强度则把源电荷对空间的作用独立表达出来。叠加原理适用于多个电荷共同产生的场。

## 高斯定律
高斯定律把闭合曲面电通量与内部电荷联系起来，在球对称、柱对称或平面对称问题中可以显著简化计算。选择合适高斯面很关键。

## 电势与电势能
电势是单位正电荷的电势能，电势差与电场力做功相关。等势面与电场线相互垂直，电场可由电势梯度得到。

## 磁场与洛伦兹力
运动电荷和电流产生磁场，带电粒子在磁场中受到洛伦兹力。判断方向时要统一速度、电流和磁场的方向约定。

## 电磁感应
法拉第定律说明磁通量变化产生感应电动势，楞次定律确定感应效应的方向。该原理支撑发电机、变压器和电磁传感器。
