# 工业互联网安全基础

## 工业场景安全目标
工业系统除了机密性和完整性，还特别重视可用性、连续生产和人员安全。安全措施必须评估对实时性、稳定性和应急操作的影响。

## 网络分区与隔离
应根据业务和风险划分生产区、控制区、管理区和外部连接区，通过防火墙、访问控制和单向传输等手段限制不必要的横向访问。

## 身份与权限管理
工业设备、运维人员和应用服务都应有可追踪身份。权限应遵循最小授权，重要操作采用多因素认证、审批和审计，避免共享账号造成责任不清。

## 安全监测与响应
监测应结合网络流量、设备行为、登录事件和配置变化建立基线。发现异常后先确认影响范围，再按预案隔离、恢复和取证，不能贸然重启关键设备。

## 安全维护与演练
补丁、备份、漏洞评估和应急演练要结合生产窗口安排。演练应验证联系人、替代设备、恢复时间和数据完整性，并将问题纳入整改闭环。
