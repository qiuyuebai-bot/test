# 数据结构与程序设计

## 线性表与链式结构
数组适合按下标访问，链表适合频繁插入和删除但访问需要遍历。选择结构时应结合访问模式、内存布局和容量变化。

## 栈与队列
栈遵循后进先出，常用于函数调用、表达式求值和回溯；队列遵循先进先出，常用于任务调度、缓冲和广度优先搜索。

## 树结构
树通过父子关系表达层次结构，二叉搜索树利用顺序支持查找，堆适合维护最值。实际使用时要关注平衡性、退化和更新成本。

## 图与遍历
图由顶点和边组成，可表示网络、依赖和路径关系。深度优先和广度优先是基础遍历方法，最短路和拓扑排序需要额外约束。

## 结构选择与测试
数据结构选择应由操作复杂度、数据规模、并发需求和可维护性共同决定。测试要覆盖空结构、单元素、重复值、边界容量和非法操作。
