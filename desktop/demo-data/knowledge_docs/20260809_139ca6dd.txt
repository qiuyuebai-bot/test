REST（Representational State Transfer）是一组软件架构原则，用于设计网络服务。

核心原则：
1. 资源导向：每个 URL 代表一个资源，名词复数形式
2. HTTP 方法语义：GET 查询、POST 创建、PUT 全量更新、PATCH 部分更新、DELETE 删除
3. 无状态：每个请求包含所有必要信息，服务端不保存客户端会话
4. 统一接口：一致的响应格式和错误处理

最佳实践：
- 使用 JSON 作为数据格式
- API 版本化（/api/v1/）
- 适当的 HTTP 状态码（200/201/400/404/500）
- 分页、过滤、排序支持
- 认证使用 Bearer Token 或 OAuth 2.0
- 限流防止滥用
