# 工业互联网边缘计算

## 边缘计算定位
边缘计算把部分采集、分析和控制能力放到靠近设备的位置，以降低时延、减少带宽和提高断网可用性。边缘与云端应按业务时效和数据规模分工。

## 边缘节点组成
边缘节点通常包括工业网关、计算资源、协议适配、数据缓存、容器运行时和远程运维组件。设计时要考虑温度、供电、存储和故障恢复。

## 实时数据处理
边缘侧可完成过滤、聚合、窗口计算、异常检测和局部控制。处理规则需要版本化，并保留原始数据摘要，便于云端复核和故障追溯。

## 云边协同
云端适合模型训练、跨设备分析和统一配置，边缘适合实时响应和本地闭环。同步机制应处理网络抖动、时钟偏差、重复消息和配置回滚。

## 边缘节点运维
节点运维应包括健康检查、日志采集、资源监测、远程升级和故障隔离。升级包需要校验来源和完整性，并支持失败后的安全回退。
