# 数据分析方法与表达

## 分析问题定义
数据分析开始前应明确业务问题、分析对象、时间范围和评价指标。问题定义越清晰，后续数据处理和结论解释越容易验证。

## 统计关系解释
相关关系不等同于因果关系。分析结果应说明数据来源、样本范围和可能的混杂因素，避免把观察到的相关性直接解释为因果结论。

## 可视化沟通
图表应服务于具体判断，选择能够突出趋势、分布或对比关系的图形，并在标题、坐标和单位中说明数据含义。

## 数据清洗与特征构造
数据清洗应先记录规则和影响范围，再处理重复、缺失、异常和单位不一致问题。特征构造要说明计算口径和时间窗口，并保留从原始数据到分析字段的追溯关系。

## 抽样与不确定性
样本选择应考虑代表性、抽样偏差和时间分布，不能只根据方便获取的数据下结论。对估计结果应说明误差范围、置信程度和适用条件，帮助使用者正确理解分析结论。
