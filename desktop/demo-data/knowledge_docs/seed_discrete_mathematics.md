# 离散数学与计算思维基础

## 命题逻辑与证明
命题逻辑使用真值和逻辑联结词表达可判断真假的陈述。直接证明、反证、归纳和构造证明是分析算法正确性与程序性质的常用方法。

## 集合与关系
集合用于描述对象的汇总，关系用于表达对象之间的对应或联系。等价关系产生划分，偏序关系可表达依赖、层次和可比较性。

## 组合计数与递推
排列、组合、容斥原理和鸽巢原理用于计算离散对象的数量。递推关系把当前规模的问题与较小规模联系起来，是分析算法复杂度的重要工具。

## 图论与布尔代数
图由顶点和边组成，可表示网络、依赖和路径；树是无环连通图，在文件系统和搜索结构中十分常见。布尔代数使用真值运算描述数字逻辑和条件判断。

## 算法复杂度与递归
算法复杂度描述输入规模增长时资源消耗的变化，常用渐进符号比较时间和空间开销。递归算法需要明确终止条件和规模缩减关系，并可通过递推式或树形展开分析复杂度。
