# 计算机网络原理基础

## 分层模型与封装
网络分层把复杂通信拆分为职责清晰的协议层。发送数据时各层添加自己的控制信息，接收端按相反顺序解封装；分层有利于替换实现和定位故障。

## 地址与路由
链路层地址用于局部网络传输，IP 地址用于跨网络寻址，路由器依据路由表选择下一跳。子网划分可以控制广播范围并提高地址规划的清晰度。

## 传输层协议
TCP通过连接管理、序号、确认、重传和流量控制提供可靠字节流；UDP开销较小但不保证交付顺序和可靠性。协议选择应依据实时性、可靠性和应用语义。

## 应用协议与排障
DNS负责名称解析，HTTP负责应用层请求与响应。排障时可按本机配置、链路连通性、地址解析、端口监听、协议响应和服务日志逐层缩小范围。

## 拥塞控制与服务质量
网络拥塞会导致排队增加、丢包和吞吐下降，传输协议通常通过速率调整和重传策略缓解影响。服务质量分析应同时关注带宽、时延、抖动和丢包率，并结合业务优先级设置策略。
