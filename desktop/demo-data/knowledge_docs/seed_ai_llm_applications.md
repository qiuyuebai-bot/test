# 大语言模型应用基础

## 语言模型能力边界
大语言模型通过学习语言模式生成内容，擅长总结、改写、问答和代码辅助，但可能产生事实错误、过时信息或不完整推理。应用设计必须保留校验机制。

## 提示与结构化输出
高质量提示应说明任务、上下文、约束、输出格式和评价标准。对需要被程序消费的结果，应使用明确的结构化格式并进行解析校验。

## 检索增强生成
检索增强生成先从可信知识源检索相关片段，再让模型基于片段回答。切片、召回、重排、引用和无结果处理都会影响最终可靠性。

## 智能体工具调用
智能体应明确可调用工具、参数契约、权限范围和失败处理。涉及写入、外部通信或高风险操作时需要确认、审计和幂等保护。

## 大模型评测与治理
评测应覆盖事实性、相关性、安全性、稳定性、延迟和成本，并准备真实业务样例与对抗样例。上线后持续记录反馈和版本变化，形成治理闭环。
