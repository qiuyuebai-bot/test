# 电气工程及其自动化基础

## 传感器与执行器
传感器把温度、压力、位移等物理量转换为可测信号，执行器把控制信号转换为机械、电气或流体动作。选型时要关注量程、精度、响应时间、接口和现场环境。

## PLC控制基础
PLC通常按照输入采样、程序执行和输出刷新循环工作。梯形图、功能块图或结构化文本用于表达控制逻辑，设计时需要处理启动、停止、互锁、故障和复位状态。

## 反馈与控制
开环控制不利用输出反馈，闭环控制通过测量结果与目标值的偏差调整输入。比例、积分和微分环节分别影响响应速度、稳态误差和变化趋势，参数应结合对象特性调试。

## 电气安全与可靠性
电气系统设计必须明确额定值、保护装置、接地和隔离要求，并在检修时执行断电、验电和挂牌等安全措施。控制系统还应考虑急停、冗余、故障安全和异常状态下的可恢复性。

## 电机与电力电子基础
电机通过电磁作用实现电能与机械能之间的转换，电力电子器件则通过开关和变换控制电能的电压、电流与频率。学习和选型时应同时考虑额定工况、效率、散热、保护和控制接口。
