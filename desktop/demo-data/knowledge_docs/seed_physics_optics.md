# 大学物理光学基础

## 几何光学
几何光学用光线近似描述反射、折射和成像。透镜成像规律与符号约定应结合光路图使用，不能只套公式而忽略物距和像距范围。

## 光的干涉
相干光叠加会产生稳定的明暗分布，光程差和相位差决定干涉条件。薄膜干涉中还要考虑反射引起的相位变化。

## 单缝与光栅衍射
衍射体现波通过狭缝或绕过障碍后的传播特性，单缝衍射和光栅衍射的极值条件不同。光栅可以利用角度差分辨不同波长。

## 偏振
偏振描述横波振动方向的有序性，偏振片、波片和双折射可以改变光的偏振状态。偏振现象也常用于应力分析和光学检测。

## 光学仪器与实验
显微镜、望远镜和干涉仪通过透镜、反射镜或分束器实现放大和测量。实验中要控制光路对准、环境振动、读数误差和仪器分辨率。
