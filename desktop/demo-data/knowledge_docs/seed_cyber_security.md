# 网络安全基础与防护实践

## 安全目标与威胁建模
信息安全通常关注机密性、完整性和可用性，同时要考虑身份可追溯和业务连续性。威胁建模应识别资产、信任边界、攻击面、潜在威胁和可验证的缓解措施。

## 身份认证与访问控制
认证回答用户是谁，授权决定用户能做什么，会话管理负责持续控制访问状态。应遵循最小权限、默认拒绝和职责分离原则，并对敏感操作保留审计记录。

## 常见漏洞与安全开发
输入校验、参数化查询、输出编码和安全的密钥管理可以降低注入、跨站脚本和凭据泄露风险。安全开发应把依赖检查、代码审查、测试和配置核查纳入交付流程。

## 监测与应急响应
安全事件处理通常包括准备、发现与分析、遏制、根除、恢复和复盘。日志应记录必要的时间、主体、动作和结果，并注意权限控制、完整性保护和隐私合规。

## 密码基础与密钥管理
密码机制应根据机密性、完整性、认证和不可否认等目标选择，并使用经过审查的标准算法和安全参数。密钥需要分级保护、限制访问、定期轮换并设计泄露后的吊销和恢复流程。
