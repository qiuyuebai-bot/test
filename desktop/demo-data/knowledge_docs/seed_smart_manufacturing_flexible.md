# 柔性生产与工业机器人

## 柔性生产特征
柔性生产通过可重构设备、可配置工艺和信息化调度适应多品种小批量订单。核心是缩短换型时间，同时保持质量、节拍和安全要求。

## 机器人工作站设计
工作站设计应明确工件流向、机器人可达范围、末端执行器、夹具、传感器和安全围栏。布局要兼顾节拍、维护通道和人员协作边界。

## 任务规划与调度
调度需要考虑订单优先级、设备能力、工艺约束、换型成本和交付时间。简单场景可使用规则，复杂场景可结合优化算法并保留人工干预入口。

## 人机协同安全
人机协同必须进行风险辨识，配置速度限制、区域检测、急停和安全联锁。任何自动恢复动作都应有明确条件，不能绕过安全保护。

## 柔性产线评价
可用换型时间、设备综合效率、订单准时率、一次合格率和人工干预次数评价柔性产线。评价指标应覆盖生产效率与安全质量，避免只优化单一指标。
