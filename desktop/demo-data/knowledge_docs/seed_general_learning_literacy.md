# 通用学习方法与信息素养

## 学习目标与任务拆解
学习任务应先转化为可观察、可检查的目标，再拆分为概念理解、练习应用和综合表达等阶段。每个阶段都应明确完成标准和复习节点，避免只记录学习时长而不检查学习结果。

## 资料检索与来源判断
检索资料时应组合使用主题词、限定词和来源筛选，优先查看教材、标准、论文和官方文档。使用结论前要核对作者、发布时间、证据范围和适用条件，避免把未经验证的内容当作事实。

## 笔记整理与知识复习
有效笔记应记录概念之间的关系、关键例题、疑问和待验证结论，而不是简单抄录原文。复习可以结合间隔重复、主动回忆和错题归因，逐步把零散信息组织成可解释的知识结构。

## 实验与项目记录
实验或项目应记录问题、假设、输入数据、操作步骤、参数、结果和异常情况。通过保留版本、日志和复现实验，可以区分偶然现象与稳定结论，并为后续改进提供依据。

## 学术规范与责任边界
学习和研究应正确标注引用来源，区分自己的分析、他人的观点和自动化工具生成的内容。涉及隐私、安全或高风险决策时，还应遵守授权范围，进行人工核验并明确结论的局限。
