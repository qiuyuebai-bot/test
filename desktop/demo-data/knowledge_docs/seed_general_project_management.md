# 项目管理与团队协作

## 目标与范围
项目目标应说明要解决的问题、交付物、完成标准和时间边界。范围变更要经过评估和确认，避免在资源不变时无限增加任务。

## 任务分解与排期
将交付物分解为可执行任务，明确依赖关系、负责人、工作量和验收方式。排期应留出风险缓冲，并根据实际进展持续更新。

## 风险管理
风险管理包括识别、评估、应对、跟踪和关闭。高概率高影响风险应有预防措施和应急方案，风险状态要在项目例会上持续复查。

## 团队沟通
沟通应明确对象、目的、结论、责任人和截止时间。重要决策要形成可追踪记录，异步协作时使用统一文档和状态标记减少信息丢失。

## 项目复盘
复盘应围绕事实分析哪些做法有效、哪些环节造成浪费以及下次如何改进。改进项要指定负责人和验证时间，避免复盘停留在口号层面。
