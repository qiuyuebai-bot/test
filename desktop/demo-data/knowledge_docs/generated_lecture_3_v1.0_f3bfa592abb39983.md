## 1. 从全连接到卷积：为什么需要CNN

在图像处理任务中，若使用全连接网络，输入图像（例如32×32×3的彩色图像）会被展平为3072维向量，第一层隐藏层若含1024个神经元，则权重数量高达300万以上。这不仅导致计算开销巨大，还容易过拟合。更重要的是，全连接层破坏了图像的空间结构，无法利用像素间的局部相关性。

CNN的核心思想是**局部连接**和**权重共享**。卷积层通过一个小的卷积核（如3×3×3）在输入上滑动，每个位置共享同一组权重。这大幅减少了参数数量，同时保留了空间结构。推导如下：

- 输入尺寸：H×W×C
- 卷积核尺寸：k×k×C，数量为F
- 输出特征图尺寸：((H-k+2P)/S+1) × ((W-k+2P)/S+1) × F
- 参数量：k×k×C×F（加上偏置）

以32×32×3输入、使用6个5×5卷积核（步长1，填充0）为例，参数量为5×5×3×6=450，而全连接第一层（若输出256）需要3072×256≈786,432。差距显著。

## 2. 卷积的数学原理与特征提取

卷积运算本质上是一个加权求和过程。对于输入图像I和卷积核K，输出特征图O在位置(i,j)的计算为：

O(i,j) = Σ_m Σ_n I(i+m, j+n) * K(m, n) + b

其中m,n遍历卷积核的维度。这个操作相当于用卷积核在图像上滑动，检测特定的局部模式，例如边缘、纹理、颜色变化等。不同卷积核可以提取不同特征，浅层卷积核通常学习边缘、角点等低级特征，深层卷积核则组合出更复杂的语义特征。

**激活函数**（如ReLU）在卷积后引入非线性，使得网络能够拟合复杂函数。ReLU定义为f(x)=max(0,x)，其梯度在正区间恒为1，缓解了梯度消失问题。

## 3. 池化（Pooling）的作用与推导

池化层用于下采样，减少空间尺寸和计算量，同时增强平移不变性。常用最大池化（Max Pooling）和平均池化（Average Pooling）。

- 最大池化：在每个池化窗口（如2×2）内取最大值。
- 平均池化：取窗口内所有值的平均。

池化层的参数量为零，因为它只做固定操作。推导输出尺寸：若输入为H×W，池化窗口为k×k，步长s，则输出为((H-k)/s+1) × ((W-k)/s+1)。

池化在一定程度上牺牲了空间细节，但换来了计算效率和对微小位移的鲁棒性。在图像分类任务中，这种折中通常是有益的。

## 4. 经典CNN架构解析

**LeNet-5**（1998年）是CNN的鼻祖，用于手写数字识别。结构：卷积-池化-卷积-池化-全连接。它的成功证明了卷积+池化+全连接的组合能有效处理图像。

**AlexNet**（2012年）在ImageNet上取得突破，引入了ReLU、Dropout和数据增强，使用两块GPU并行训练。其结构包含5个卷积层和3个全连接层，展示了深度网络在大规模数据上的威力。

**VGGNet**（2014年）提出使用连续的小卷积核（3×3）堆叠代替大卷积核，在相同感受野下增加非线性，同时减少参数量。例如，两个3×3卷积堆叠等效于一个5×5卷积，但参数量为2×(3×3×C×C) vs 5×5×C×C，前者为18C²，后者为25C²，节省了28%。

**ResNet**（2015年）引入残差连接，解决深层网络退化问题。残差块输出为F(x)+x，使得网络可以学习恒等映射，从而训练更深的网络（如152层）。推导：若目标函数为H(x)，则残差块学习F(x)=H(x)-x，优化残差比直接优化H(x)更容易。

## 5. 训练技巧与正则化

- **数据增强**：随机裁剪、水平翻转、颜色抖动等，增加数据多样性，减少过拟合。
- **Dropout**：在训练时随机丢弃部分神经元，强制网络学习冗余特征。
- **批量归一化（Batch Normalization）**：对每个mini-batch的激活值进行标准化，加速收敛，允许使用更大的学习率。
- **学习率调度**：如阶梯式下降、余弦退火等，帮助模型收敛到更优解。

## 6. 应用边界与局限

CNN在图像分类、目标检测、语义分割等领域表现卓越，但并非万能。其局限性包括：

- **对全局依赖建模能力有限**：卷积核感受野有限，难以捕捉远距离像素间的关系。对于需要全局上下文的任务（如全景分割），CNN可能不如Transformer等自注意力模型。
- **平移等变性而非不变性**：CNN对输入平移具有等变性（即特征随目标移动而移动），但不具备完全的平移不变性，通常依赖池化来近似。
- **数据需求大**：深度CNN通常需要大量标注数据，在小数据集上容易过拟合，需借助迁移学习。
- **可解释性差**：虽然可视化技术（如Grad-CAM）能帮助理解，但CNN内部决策过程仍较难解释。

## 7. 与盲区知识点的关联

本讲义涉及CNN基础，但学习者在“模型蒸馏”和“分布式训练”方面存在盲区。理解CNN后，可以进一步探索：
- **模型蒸馏**：将大CNN（教师网络）的知识迁移到小CNN（学生网络），通过软标签训练，实现模型压缩。
- **分布式训练**：在训练大型CNN时，常采用数据并行或模型并行，将计算分布到多GPU，以加速训练。

建议在学习CNN后，针对这两个方向进行专项学习，以完善知识体系。

## 8. 实践建议

- 使用PyTorch或TensorFlow实现一个简单的CNN（如LeNet）并在MNIST上训练，观察不同超参数的影响。
- 尝试使用预训练的ResNet进行迁移学习，解决一个小型图像分类问题。
- 利用学习率调度和Batch Normalization，提高模型收敛速度。

总结：CNN通过局部连接、权重共享和层次化特征提取，成为计算机视觉的基石。理解其原理推导有助于把握其适用范围，避免盲目使用。在实际应用中，应根据任务特点，权衡CNN的优缺点，并考虑结合其他技术。
