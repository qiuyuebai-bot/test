# 时间序列分析基础

## 时间序列组成
时间序列通常包含趋势、季节性、周期性、随机波动和异常点。分析前应明确时间粒度、采样间隔、时区和缺失记录的含义。

## 时间对齐与清洗
清洗时要处理重复时间戳、缺失时间段、异常值和不规则采样。填补方法应结合业务含义，并保留原始值与处理标记以便追溯。

## 平滑与分解
移动平均和指数平滑可以降低短期噪声，分解方法可以分离趋势和季节项。平滑窗口会影响响应速度，不能把平滑结果误认为真实观测。

## 时间序列验证
时间序列不能随机打乱后划分训练集和测试集，应使用按时间顺序的滚动或留出验证。评价时要与基准方法比较，并关注不同时间段的误差。

## 预测结果应用
预测应同时提供预测值、区间和更新时间。业务应用还要考虑库存、产能、风险和人工调整，预测模型不能替代对异常事件的及时判断。
