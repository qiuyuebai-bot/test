# 算法设计与复杂度分析

## 问题建模
算法设计先要明确输入、输出、约束、异常情况和正确性标准。把业务问题转化为可计算模型，通常比直接选择某种算法更重要。

## 复杂度分析
时间复杂度描述输入规模增长时的计算量变化，空间复杂度描述额外存储需求。分析时要关注主导项、最坏情况和实际常数，而不是只背记符号。

## 分治与递归
分治把问题拆为规模更小的子问题，再合并结果。递归实现需要明确终止条件、子问题收敛性和栈空间，必要时可改写为迭代。

## 贪心与动态规划
贪心每一步选择当前最优，适用于具有相应结构的问题；动态规划利用子问题重叠和最优子结构保存中间结果。二者都需要证明选择或状态转移的合理性。

## 算法验证
验证应覆盖空输入、边界值、重复值、极端规模和非法输入。除样例测试外，还可使用性质测试、随机测试和基准测试检查正确性与性能。
