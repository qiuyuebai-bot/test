# 微积分基础与工程应用

## 极限与连续
极限描述变量在趋近某一点或无穷远处的变化趋势，连续性要求函数在该点有定义且极限等于函数值。极限是导数、积分和数值分析中误差控制的基础。

## 导数与变化率
导数表示函数在一点附近的瞬时变化率，也可理解为局部线性近似的斜率。工程中速度是位移对时间的导数，灵敏度和梯度也可用导数描述。

## 积分与累积量
定积分可表示连续量在区间上的累积，微积分基本定理建立了积分与原函数之间的联系。电荷、能量、位移等量常可通过对相应速率积分得到。

## 多元函数与优化
多元函数使用偏导数和梯度描述各变量对结果的影响。梯度方向给出局部增长最快的方向，梯度下降则通过反方向迭代寻找目标函数的较小值。

## 级数与近似
级数把复杂函数表示为一组简单项的累加，收敛性决定近似是否具有稳定意义。泰勒展开可用于局部近似，实际计算还要结合截断误差和有效适用范围。

## 微分方程与动态建模
微分方程用变量及其导数描述系统随时间或空间的变化，电路、机械和控制系统中都很常见。建模时应明确初始条件、边界条件和参数含义，再选择解析或数值方法求解。
