# 自动控制原理基础

## 控制系统基本概念
控制系统由被控对象、控制器、执行器、测量环节和反馈通道组成。分析时应明确输入、输出、扰动和性能指标，区分开环与闭环结构。

## 传递函数与方块图
在线性定常条件下，传递函数描述输入与输出的关系。方块图化简和信号流图可以帮助分析串联、并联和反馈连接，但要注意初始条件假设。

## 稳定性分析
稳定性表示系统受到有限扰动后响应是否有界。可通过特征根、劳斯判据或频域方法分析，设计时还要留出足够稳定裕度。

## 动态性能指标
上升时间、峰值时间、超调量、调节时间和稳态误差描述系统响应速度与精度。指标之间常存在权衡，应结合对象约束综合设计。

## 控制器设计
比例、积分和微分作用分别影响响应速度、稳态误差和变化趋势。参数整定要考虑噪声、饱和、采样周期和执行器限制，并通过仿真与实验验证。
