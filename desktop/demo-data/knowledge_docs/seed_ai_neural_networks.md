# 神经网络训练基础

## 神经元与网络层
神经元对输入进行加权求和并经过激活函数，多个神经元组成层，多层网络可以学习逐级抽象的表示。网络结构应与输入特征和任务复杂度匹配。

## 损失函数
损失函数衡量预测与目标之间的差异，分类常用交叉熵，回归常用平方误差或绝对误差。损失函数应与优化目标和输出形式保持一致。

## 反向传播
反向传播利用链式法则计算损失对参数的梯度，再由优化器更新参数。理解梯度流向有助于定位梯度消失、梯度爆炸和维度错误。

## 训练稳定性
学习率、批大小、初始化、归一化和正则化都会影响训练稳定性。应通过训练曲线、验证曲线和梯度统计判断模型是否欠拟合或过拟合。

## 实验复现
神经网络实验应固定或记录随机种子、数据版本、代码版本、硬件环境和超参数。报告结果时同时给出多次运行波动，避免把偶然结果当作稳定提升。
