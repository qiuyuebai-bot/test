# 大学物理基础与工程认知

## 力学与守恒定律
牛顿运动定律建立力、质量和加速度之间的关系，动量、角动量和机械能守恒则提供了分析复杂运动的统一视角。建模时要明确参考系、约束条件和系统边界。

## 电场与电势
电场描述电荷对空间中其他电荷的作用，电势差与单位电荷移动时电场力做功相关。电场强度是矢量，电势是标量，二者可通过梯度关系联系。

## 电磁感应与波动
变化的磁通量会产生感应电动势，这一规律是发电机、变压器和许多传感器的基础。波动传播能量和信息，频率、波长、相位和阻抗决定了系统的响应特性。

## 热学与实验方法
温度、热量和内能描述热学系统的不同方面，热力学定律约束能量转换和过程方向。实验分析应报告测量不确定度、误差来源、重复性和适用条件。

## 光学与现代物理
几何光学关注反射、折射和成像，波动光学解释干涉、衍射和偏振等现象。量子化和波粒二象性是理解半导体、激光和现代传感器等技术的基础，应结合实验现象理解模型边界。
